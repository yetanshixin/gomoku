# 五子棋（Gomoku）

纯前端实现的五子棋小游戏，无需后端，可直接部署到 GitHub Pages。

## 功能

- **本地双人对战**：两个玩家在同一页面轮流交替落子。
- **人机对战**：可选电脑执黑（先手）或执白（后手），固定困难难度（最强棋力）。
- **悔棋**：双人模式退一步；人机模式退回两步（人类一步 + 电脑一步），回到你的回合。
- **键盘操作**：方向键 / WASD 移动选中位置，回车或空格落子。
- **移动端适配**：棋盘随屏幕缩放，触屏落子采用「点选 → 确认落子」二级确认，防止误触。
- **音效**：落子声、胜利音、失败音（Web Audio 实时合成，无需音频文件）。
- **胜利彩带**：获胜时全屏彩带动效。
- **对局导出 / 复盘**：胜负弹窗里的「复盘」一键跳转复盘模式并自动加载当前对局；复盘面板里可复制对局码，也支持「下一步 / 上一步 / 跳至开局 / 跳至终盘」。

## 规则

- 15×15 棋盘，无禁手（自由规则），黑方先手。
- 横、竖、斜任意方向连成五子即胜。

## 对局格式

采用标准五子棋记谱坐标：**天元 H8**，横坐标 A~O（左到右），纵坐标 1~15（**从下到上**）。

导出/复盘格式：`G1:` 前缀 + 落子序列，每步 = 列字母(a~o) + 行号(1~15)，连续拼接。

例如 `G1:h8h9i9j8` 表示：黑 h8（天元）、白 h9、黑 i9、白 j8。黑先手固定，颜色按先后交替，无需额外记录。

## 本地运行

直接用浏览器打开 `index.html` 即可（无构建、无依赖）。

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库，将本目录内文件（`index.html`、`style.css`、`game.js`、`ai.js`）推送到仓库：

   ```bash
   git init
   git add .
   git commit -m "五子棋游戏"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```

2. 在仓库 **Settings → Pages** 中，将 **Source** 设为 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存。

3. 稍等片刻，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可游玩。

## AI 说明

- **必胜地毯谱（核心）**：接入无禁手五子棋黑棋必胜地毯谱（从「五子棋终结者」逆向解出的完整版，73115 节点，8 向对称压缩为 35 个白棋响应对称类，覆盖白棋全部 224 个响应）。黑①天元后白棋任意走法，黑棋都能沿谱必胜。
- 电脑执黑：优先查地毯谱走**确定必胜手**；脱谱时回退「VCT 连杀 + 双杀 + Minimax/Alpha-Beta」。
- 电脑执白：查地毯谱选「让黑棋赢得最慢」的**最顽强防守点**，脱谱时用开局防守库 + 引擎拖延。
- 自由规则下黑方（先手）必胜；本实现已接近「五子棋终结者」效果。

## 电脑选点逻辑（getBestMove 决策顺序）

电脑每一步按下面的顺序判断，先命中谁就走谁：

1. **必胜地毯谱**：局面匹配地毯谱 → 走确定必胜手（8 向对称查表）
2. **立即五连**：自己下一步能五连 → 直接赢
3. **堵对方五连**：对方下一步能五连 → 必须堵（唯一优先级最高的堵拦）
4. **活四**：自己下出活四（两端都能五连）→ 必胜
5. **VCT 连杀**：连续冲四/活三强制取胜 → 走反杀
6. **堵对方双杀**：对方四四/四三/三三 → 堵（交叉点 + 所有延伸点里择优）
7. **堵对方活三**：堵对方活三（两端里择优）
8. **自己双杀**：下出四四/四三/三三 → 必胜（所有双杀点里择优）
9. **Minimax 搜索**：以上都没有 → 博弈树搜索找评分最高（含「必胜反杀」）
10. **堵对方冲四**：堵冲四（唯一五连点）

### 选点原则（攻防统一）

所有「堵哪边 / 下哪边」都用同一套方法：

- **枚举候选点**：交叉点、活三两端、冲四五连点、双杀点……全部收集
- **pointScore 评分**：计算「自己棋型 − 对方棋型」的分值
- **择优**：选分值最高的那个

这样「堵交叉点」会顺便挑「对自己进攻最有利」的点，实现**一子两用**——防守的同时搭起自己的进攻，也就是「反守为攻」。

### 评分等级

五连 > 活四 > 冲四 > 活三 > 眠三 > 活二 > 眠二 > 单子；跳四 = 冲四，跳三 = 活三（跳只是隔空，威胁等级相同）。

### 核心原则

脱谱后「主动找必胜（VCT / 搜索）」优先于「被动防守（堵双杀 / 活三 / 冲四）」，唯一例外是「对方下一步五连」必须最优先堵。
